My last post here was in March 2021. A lot has changed since then. I moved from software engineering into DevOps at DHL, and then into platform work at Atlas Copco, where I'm the product owner for GitHub Copilot and Azure DevOps across the group.

So the blog has a new home too. It now runs on **GitHub Pages**: posts are Markdown files in a repository, changes go through pull requests, and the whole site is versioned like any other code I work on. All the old posts are still here, at the same URLs.

## What's coming

I'll write about the things I actually do at work:

- **Rolling out GitHub Copilot to 2,000+ engineers.** Governance, onboarding, training and support: what worked and what I'd do differently.
- **Running Azure DevOps as a group service.** The governance model, cutting the number of organizations in half, and backing up the platform.
- **Self-service cloud automation.** Azure provisioning through ServiceNow, with Terraform and Bicep templates behind it.
- **Communities and InnerSource.** Starting a DevOps Community of Practice and getting teams to reuse each other's code.
- **Scripts from my toolbox.** Small PowerShell and automation helpers I keep coming back to.

See you at GitHub Universe in San Francisco.
